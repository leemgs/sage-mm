# Highlights — Journal of Systems Architecture

> Elsevier "Highlights" file. 3–5 bullet points, **each ≤ 85 characters**
> including spaces. Submit as a **separate** file named `Highlights` in the
> submission system (not embedded in the manuscript). A LaTeX `highlights`
> environment version is in `HIGHLIGHTS_JSA.tex`.
>
> ⚠️ These describe the *design and methodology*, which hold regardless of the
> data. Do not add a highlight that quotes a numeric improvement until it is
> backed by a versioned observed device-measurement bundle.

- Coordinates heap sizing, interop, and page reclamation under one memory budget
- Only one online controller adapts; heap and interop reduce load it must handle
- Fail-closed guards bound madvise reclamation to clean file-backed code pages
- Full-factorial G/I/R/C protocol reports interactions, cost, and run-level CIs
- Open reference kit reproduces the control logic apart from vendor firmware
