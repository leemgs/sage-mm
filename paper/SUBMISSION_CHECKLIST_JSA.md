# JSA submission checklist — SAGE-MM

Target venue: **Journal of Systems Architecture** (Elsevier, `elsarticle`
class, submitted through Editorial Manager). Publish under the **subscription**
route (no APC); do **not** select Gold Open Access.

This checklist is the single source of truth for what is prepared and what the
author must still do. Nothing here fabricates a result: the manuscript compiles
as an internal, watermarked draft, and the fail-closed gate
(`scripts/check_jsa_readiness.py`) refuses to call it submission-ready until the
real evaluation exists.

## 3. BLOCKERS the author must clear before clicking Submit

These are reported live by `python3 scripts/check_jsa_readiness.py`:

1. **Real Results.** The manuscript is built with `\includesimulationtrue`
   (preregistered hypotheses + simulation dry-run + proxy-harness table). A
   submission needs vendor DTV Mono/.NET6 device measurements: run the
   preregistered full-factorial G×I×R×C campaign (≥30 cold-reset runs/cell,
   EventPipe/vendor-GC trace, per-mapping `Private_Clean`, ≥30 min and 8 h
   durations), regenerate `paper/generated/observed-results.tex` from that
   bundle, then set `\includesimulationfalse` in `paper/sagemm-tecs.tex` and
   rerun `scripts/make_jsa.py`. The current `observed-results.tex` is the ARM64
   Linux **proxy harness** (n=3, Python collector) and is explicitly *not*
   firmware evidence.
2. **Author affiliation.** Replace `[Institution]`, `[City]`, `[Country]` in the
   `PREAMBLE` of `scripts/make_jsa.py` (single source), then regenerate.
3. **Bibliography verification.** `paper/sagemm.bib` still carries "verify"
   notes and provisional identifiers (AGC/DumpKV preprint-DOI collision, the
   Platinum ACM index id, `others` author lists, vendor-Mono/.NET manuals).
   Replace each with the publisher-of-record record and final DOI, expand the
   related-work set, and remove the notes.

## 4. Recommended before submission (not gated)

- Convert the three placeholder SVG figures and the architecture figure to
  vector PDF/EPS; confirm they are legible in single-column width.
- Fill the "Use of generative AI" disclosure in `DECLARATIONS_JSA.md` to match
  the actual process, or delete it.
- Add 3 suggested reviewers (no conflict of interest) in the cover letter / EM.
- Confirm current JSA author instructions: page/length policy, figure formats,
  reference style, and the subscription-vs-OA publishing-option step.
- Run `bash scripts/build_jsa.sh` locally with a TeX Live that has
  `elsarticle.cls` to resolve any overfull-box / citation warnings.

## 5. Final gate

From the repository root:

```bash
bash scripts/build_jsa.sh --submission   # fails until §3 is cleared, by design
```

When it prints `JSA submission readiness gate passed` and produces
`paper/sagemm-jsa.pdf`, the manuscript, highlights, cover letter, and
declarations are ready to upload through Editorial Manager under the
subscription route.
